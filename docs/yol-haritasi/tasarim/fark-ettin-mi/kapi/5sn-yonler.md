# Yöntem değişikliği: üç yön (2026-10-01)

İki tur dolunca (tur1, tur2) aynı ekranlar üç yönde çizildi: A sade kartlar, B sahne arka planda + cam katmanlar,
C gözlem defteri. Maket: `maket/yonler.html?d=A|B|C&s=<ekran>&theme=…`. Görüntüler: `maket/yon1/`.

Dört bağımsız değerlendirici (hemşire, sanat yönetmeni, esnaf, öğrenci). Tek yön seçimi: **A 3, C 1, B 0.**

| Ekran | A evet | B evet | C evet |
|---|---|---|---|
| intro | 3/4 | 0/4 | 3/4 |
| change | 3/4 | 0/4 | 4/4 |
| found | 3/4 | 0/4 | 3/4 |
| ask | 4/4 | 0/4 | 0/4 |
| ask2 | 4/4 | 0/4 | 0/4 |
| result | 0/4 | 0/4 | 0/4 |
| home (yalnız A) | 3/4 | – | – |

Ölçü sözcüğü: dördü de "16 nesne"yi en anlaşılır buldu ("ayrıntılı sahne", "16'lık sahne" değil). → Birim `nesne`.

A'ya taşınan ortak düzeltmeler:
- 320'de görev görselinde mavi araba görünmüyordu (3/4) → kırpım yolu da gösteriyor.
- "Sahnede 14 şey" belirsiz (2/4) → "Sahnede 14 nesne".
- Bulundu ekranında önceki renk yok (1/4), kutlama yok (1/4) → "Buldun!" + "Şapka kırmızıydı, mavi oldu" renk
  noktalarıyla.
- "Görmedim" çipi düğme sanıldı (3/4) → çip kalktı, alt satır "Görmedin; yine de tahmin et."
- Sonuç: "kesikli halka: başlangıcın, 11" şifre gibi (4/4) → "Başlangıcın 11 → bugün 16"; nokta ölçeğinde başlangıca
  kadar soluk, sonrası parlak. 320'de sahne şeride iniyordu → 320'de sahne yok, bulunan değişiklik satır olarak.
- Ana sayfa alt yarısı boş (3/4), "Yolunda yeni bir durak var" belirsiz (1/4) → yolun öbür durakları; "Yoluna yeni
  bir durak geldi. Caddede neyin değiştiğini bulacaksın."
- İddia sınırı cümlesi görev ekranında "neden yapayım" dedirtiyor (3/4) → maket önerisi: görev ekranından kalkar,
  sonuç ekranının ve "Neye dayanıyor?" sayfasının altında durur. **Sahip kararı** (PLAN §9).
